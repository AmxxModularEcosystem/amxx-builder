# `validate_manifest`

Проверяет `amxbuild.yml` на ошибки и возвращает список проблем.

## Параметры

| Поле | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `manifest` | `string` | — | Путь к `amxbuild.yml`. Если не указать, ищет сам в рабочей папке |

## Результат

Возвращает `valid: true/false`, список `errors` и `warnings`.

## Примеры

```
— Проверь мой amxbuild.yml на ошибки
— Валиден ли манифест?
```
