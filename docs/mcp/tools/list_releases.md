# `list_releases`

Показывает доступные версии GitHub репозитория — релизы или git-тэги. Удобно, когда нужно узнать, какие версии зависимости существуют.

## Параметры

| Поле | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `repo` | `string` | ✓ | Репозиторий: `"owner/repo"`, например `"AmxxModularEcosystem/ParamsController"` |
| `limit` | `number` | — | Сколько версий показать. По умолчанию `10` |
| `includeAssets` | `boolean` | — | Показывать ассеты релиза (имя, размер, скачивания). Только для релизов |
| `tags` | `boolean` | — | Показать git-тэги вместо релизов. Полезно, если у репо нет GitHub Releases |
| `token` | `string` | — | GitHub PAT |

## Примеры

```
— Какие версии есть у AmxxModularEcosystem/ParamsController?
— Покажи последние 5 релизов rehlds/ReAPI
— Есть ли тэг v2.0 в этом репозитории?
```
