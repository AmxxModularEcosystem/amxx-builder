# `get_amxmodx_include`

Скачивает (если нужно) стандартный компилятор AMXX и показывает содержимое его `.inc` файлов. Можно искать по подстроке внутри файлов.

## Параметры

| Поле | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `manifest` | `string` | — | Путь к `amxbuild.yml` для определения версии AMXX |
| `version` | `string` | — | Версия AMX Mod X. Если не указать — из манифеста или последняя |
| `file` | `string` | — | Какой файл показать: `"amxmodx.inc"`, `"core.*"`, `"*.inc"`. По умолчанию все |
| `grep` | `string` | — | Искать подстроку в содержимом (регистр не важен) |
| `before` | `number` | — | Сколько строк до совпадения показывать. По умолчанию `0` |
| `after` | `number` | — | Сколько строк после совпадения показывать. По умолчанию `0` |

## Примеры

```
— Покажи содержимое amxmodx.inc
— Какие функции объявлены в core.inc?
— Найди в stdlib все упоминания register_plugin
```
