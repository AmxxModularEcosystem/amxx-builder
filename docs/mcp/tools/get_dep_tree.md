# `get_dep_tree`

Строит дерево зависимостей: какие зависимости от каких зависят. Можно стартовать от манифеста или от списка deps.

## Параметры

| Поле | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `manifest` | `string` | * | Путь к `amxbuild.yml`. Зависимости из `repos` и `globalDeps` подхватятся автоматически |
| `deps` | `array` | * | Список зависимостей вручную: `["owner/repo@ref", ...]` |
| `depth` | `number` | — | На сколько уровней углубляться (`0` — безлимит). По умолчанию `0` |
| `token` | `string` | — | GitHub PAT |
| `no_fetch` | `boolean` | — | Не ходить в сеть, только кэш |

\* Нужно указать **один из**: `manifest` или `deps`.

## Примеры

```
— Покажи полное дерево зависимостей для моего проекта
— Какие транзитивные зависимости есть у AmxxModularEcosystem/VipModular?
```
