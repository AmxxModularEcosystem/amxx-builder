# `resolve_manifest`

Читает `amxbuild.yml`, подмешивает значения по умолчанию, применяет переопределения и возвращает готовый манифест. `.env` файл рядом с манифестом подгружается автоматически.

## Параметры

| Поле | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `manifest` | `string` | — | Путь к `amxbuild.yml`. Если не указать, ищет сам в рабочей папке (`amxbuild.yml` → `amxbuild.yaml` → `manifest.yml`) |
| `set` | `string[]` | — | Переопределить поля через точку: `["version=1.2", "output.pack=false"]` |
| `define` | `string[]` | — | Добавить defines компилятора: `["DEBUG", "VERSION=1.2"]` |

## Примеры

```
— Прочитай и покажи полный манифест со всеми настройками
— Что получится, если в манифесте переопределить версию и отключить архив?
— Покажи amxbuild.yml после применения --set и --define
```
