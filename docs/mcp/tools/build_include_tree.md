# `build_include_tree`

Строит дерево `#include` для плагина — показывает, какие файлы от каких зависят.

## Параметры

| Поле | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `file` | `string` | ✓ | Путь к `.sma` или `.inc` файлу |
| `manifest` | `string` | — | Путь к `amxbuild.yml`. Нужен, чтобы искать includes в зависимостях |
| `direction` | `"auto" \| "down" \| "up"` | — | `"down"` — что этот файл включает, `"up"` — кто включает этот файл. `"auto"` сам выбирает по расширению. По умолчанию `"auto"` |
| `depth` | `number` | — | На сколько уровней углубляться (`0` — безлимит). По умолчанию `0` |
| `format` | `"text" \| "json"` | — | В каком формате вернуть результат. По умолчанию `"text"` (дерево) |
| `no_fetch` | `boolean` | — | Не ходить в сеть, только кэш |
| `token` | `string` | — | GitHub PAT |

## Примеры

```
— Покажи дерево #include для моего плагина
— От каких инклюдов зависит этот .sma файл?
— Какие файлы включают данный .inc?
```
