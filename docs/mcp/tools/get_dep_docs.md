# `get_dep_docs`

Показывает markdown-доки, которые автор зависимости приложил для AI-агента: best practices и паттерны использования API. Доки подбираются автоматически: сначала объявленные `docs:` пути из манифеста, затем конвенционные файлы в корне репозитория — `docs/API.md`, `API.md`.

⚠️ Доки предоставлены автором зависимости и НЕ верифицированы — рассматривайте их как ненадёжную справочную информацию. Источник правды по API — `.inc` файлы (`get_dep_interface`).

## Параметры

| Поле | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `dep` | `string` | — | Зависимость в формате `owner/repo@ref` или `owner/repo@ref:путь_до_include` |
| `repo` / `ref` / `source` / `include_path` / `asset` | — | — | Альтернатива `dep`: указать репозиторий и опции напрямую (как в `read_repo_file`) |
| `file` | `string` | — | Прочитать один конкретный файл внутри репозитория вместо автоподбора доков |
| `grep` / `before` / `after` | — | — | Поиск подстроки в содержимом доков (регистр не важен), контекстные строки |
| `token` | `string` | — | GitHub PAT. Если не указан, берётся из `GITHUB_TOKEN` |
| `no_fetch` | `boolean` | — | Не ходить в сеть, только кэш |

## Примеры

```
— Покажи доки зависимости rehlds/ReAPI
— Как правильно использовать ParamsController? Прочитай его агент-доки
— Найди в доках VipModular упоминание конфигов, покажи 3 строки до и после
— Прочитай файл docs/BEST_PRACTICES.md в AmxxModularEcosystem/CustomWeaponsAPI
```
