# `list_amxmodx_incs`

Показывает список стандартных `.inc` файлов AMXX (amxmodx.inc, core.inc, float.inc и т.д.).

## Параметры

| Поле | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `manifest` | `string` | — | Путь к `amxbuild.yml`. Нужен, только чтобы указать версию AMXX через манифест |
| `version` | `string` | — | Версия AMX Mod X (например `"1.10.5428"`). Если не указать — берётся из манифеста или последняя доступная |
| `pattern` | `string` | — | Фильтр по имени: `"core.*"`, `"cs*.inc"`. По умолчанию `"*.inc"` (все) |

## Примеры

```
— Какие стандартные инклюды есть в AMXX?
— Покажи все .inc файлы amxmodx версии 1.10
— Есть ли в stdlib файл core.inc?
```
