# `resolve_include`

Находит, какой файл скрывается за `#include` директивой. Понимает все формы: `#include <file>`, `#include "file"`, `<file>`, `"file"`. Если у файла нет расширения — сам добавляет `.inc`.

## Параметры

| Поле | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `directive` | `string` | ✓ | Директива: `"#include <amxmodx>"`, `"#include \"ColorChat\""`, или просто `"<amxmodx>"` |
| `sma_file` | `string` | — | Путь к `.sma` файлу. Нужен для `#include ""` — чтобы знать, где искать локальный файл |
| `manifest` | `string` | — | Путь к `amxbuild.yml`. Если указать, будет искать ещё и среди зависимостей из манифеста |
| `version` | `string` | — | Версия AMXX для поиска в stdlib. Если не указать — из манифеста или последняя |
| `grep` | `string` | — | Искать подстроку внутри найденного файла |
| `before` | `number` | — | Сколько строк до совпадения |
| `after` | `number` | — | Сколько строк после совпадения |

## Примеры

```
— Найди, что скрывается за #include <amxmodx>
— Покажи содержимое файла для #include "ColorChat" из моего плагина
— Куда ведёт #include <reapi> в этом проекте?
```
