# `get_cache_info`

Показывает, что лежит в кэше сборки: скачанные компиляторы, клоны репозиториев, релиз-ассеты.

## Параметры

| Поле | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `manifest` | `string` | — | Если указать, покажет ещё и локальный кэш ассетов рядом с манифестом |

## Примеры

```
— Покажи содержимое кэша
— Что закэшировано для этого проекта?
— Есть ли в кэше компилятор?
```
